# Severity

Each finding has a severity: CRITICAL, HIGH, MEDIUM or LOW. A CRITICAL finding blocks.
CRITICAL findings are listed first. Another CRITICAL example.

Set `MUST` in the config, or `NEVER`, or `ALWAYS`.
The scope is ALL | ANY | NONE, the mode is ONLY/NOT, and the flag reads "REQUIRED".

MUST NEVER ALWAYS DO NOT IMPORTANT MANDATORY
