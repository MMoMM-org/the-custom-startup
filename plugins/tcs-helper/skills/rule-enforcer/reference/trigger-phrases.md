# Trigger Phrases — Rule Enforcer

Regex patterns that signal recurrence: the user is describing a mistake, habit, or rule they keep
violating. One pattern per line inside each language's code fence.

Patterns are matched case-insensitively against the full prompt text.

To add a language: add a `## <Language>` heading followed by a code-fenced block of regexes.

---

