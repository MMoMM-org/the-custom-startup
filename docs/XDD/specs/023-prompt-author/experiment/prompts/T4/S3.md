# ledgerlite

Small Python CSV ledger reporting tool (stdlib only, python3). Converts transactions to EUR and prints grouped totals. Code is in `ledgerlite/`, tests in `tests/`, helper scripts in `scripts/`.

## Commands

Use `./scripts/dev.sh` as the entry point:

- `./scripts/dev.sh test [unittest args]` runs the tests. Use this, not bare `python3 -m unittest`: the script sets `LEDGERLITE_HOME` to `tests/fixtures`, which `test_report.py` and `test_cli.py` need (they fail at import or at runtime without it). It also writes `.dev-test-stamp` (gitignored); ignore that file.
- `./scripts/dev.sh lint` runs `scripts/lint.py` (max line length 99, no tabs, no trailing whitespace, final newline) over `ledgerlite tests scripts`, then checks that `_rates.py` is up to date.
- `./scripts/dev.sh fmt` auto-fixes whitespace issues only. Over-long lines and tabs must be fixed by hand.
- `./scripts/dev.sh gen` regenerates `ledgerlite/_rates.py`.

Run a single test module with e.g. `./scripts/dev.sh test tests.test_parser`.

Run the CLI: `python3 -m ledgerlite.cli report [--by category|month] [FILE]`. Without FILE it reads `$LEDGERLITE_HOME/ledger.csv` and raises `RuntimeError` if the variable is unset.

## Exchange rates

`ledgerlite/_rates.py` is generated from `data/rates.csv` by `scripts/gen_rates.py`. Never edit `_rates.py` by hand (the README's mention of it as the place for rates is outdated). To change a rate or add a currency, edit `data/rates.csv` and run `./scripts/dev.sh gen`, then commit both files. `lint` fails if they are out of sync. Rates are stored as EUR per one unit of the currency.

## Conventions

- Code in `ledgerlite/` uses relative imports (`from .model import ...`). Tests import the package as `ledgerlite`.
- Parse problems raise `ParseError` with the CSV line number (header is line 1, first data row is line 2). Keep that numbering when changing the parser.
- Unknown currency codes raise `UnknownCurrency`.
- Tests use `unittest` (no pytest). Tests that need ledger data use `tests/fixtures/ledger.csv`; if you change that file, update the expected totals in `tests/test_report.py` and the assertions in `tests/test_cli.py`.
- Before finishing a change, run `./scripts/dev.sh lint` and `./scripts/dev.sh test` and report any failures as they are.
