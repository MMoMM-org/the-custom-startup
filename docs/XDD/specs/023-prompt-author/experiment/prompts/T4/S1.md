# ledgerlite

Small Python CLI (standard library only, no dependencies) that reads a CSV ledger and prints totals per category or month, converted to EUR. Entry point: `python3 -m ledgerlite.cli report [--by category|month] [FILE]`.

## Commands

Use `./scripts/dev.sh` for everything:

- `./scripts/dev.sh test [unittest args]` runs the tests. Use this rather than bare `python3 -m unittest`: the script sets `LEDGERLITE_HOME` to `tests/fixtures`, which `test_cli.py` and `test_report.py` need. Without it they fail at import or at `config.home()` with "LEDGERLITE_HOME is not set". The README's bare `python3 -m unittest` command is incomplete for this reason.
- `./scripts/dev.sh lint` runs the style checker (`scripts/lint.py`) and then checks that `ledgerlite/_rates.py` is up to date.
- `./scripts/dev.sh fmt` auto-fixes whitespace issues. It does not wrap long lines or replace tabs; fix those by hand.
- `./scripts/dev.sh gen` regenerates `ledgerlite/_rates.py`.

Run a single test module or case by passing unittest args, e.g. `./scripts/dev.sh test tests.test_parser.ParseCsvTest.test_bad_amount_reports_line`.

`dev.sh test` writes `.dev-test-stamp` (gitignored) containing the exit status. Ignore it; don't commit it or edit it.

## Exchange rates

`data/rates.csv` is the source of truth. `ledgerlite/_rates.py` is generated from it by `scripts/gen_rates.py` and carries a source hash. Never edit `_rates.py` by hand (the README line pointing at it as the place for rates is misleading). To change a rate or add a currency, edit `data/rates.csv`, then run `./scripts/dev.sh gen`. `lint` fails if the two are out of sync. Rates are EUR per one unit of the currency; EUR must stay at 1.0.

## Style

Enforced by `scripts/lint.py`: max line length 99, no tabs, no trailing whitespace, file ends with a newline. Applies to `.py` and `.sh` under `ledgerlite`, `tests`, and `scripts`. Run `lint` before finishing a change.

## Code layout

- `parser.py`: CSV text to `model.Transaction` (frozen dataclass). Raises `ParseError` with the 1-based file line number (header is line 1).
- `currency.py`: conversion via the generated rate table; raises `UnknownCurrency`.
- `report.py`: grouping, totals, and plain-text table rendering.
- `config.py`: reads `LEDGERLITE_HOME`; `home()` raises `RuntimeError` if unset.
- `cli.py`: argparse wiring. `main(argv, out)` takes an output stream so tests can capture it.

## Tests

Tests use `unittest` (not pytest) and live in `tests/`, one module per source module. The shared fixture is `tests/fixtures/ledger.csv`, and `test_report.py` asserts exact totals computed from it. If you change the fixture, update those expectations too. Add tests for new behaviour and bug fixes alongside the existing ones.
