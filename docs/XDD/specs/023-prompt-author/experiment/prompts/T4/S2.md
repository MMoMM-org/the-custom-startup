# ledgerlite

Small Python CSV ledger reporting tool (stdlib only, no dependencies). Converts transactions to EUR and prints totals grouped by category or month.

## Commands

Use `./scripts/dev.sh` as the entry point:

- `./scripts/dev.sh test [args]` — run the tests. Sets `LEDGERLITE_HOME=tests/fixtures`, which the CLI and report tests require. Extra args go to `unittest discover`, e.g. `./scripts/dev.sh test tests.test_parser`.
- `./scripts/dev.sh lint` — style check (`scripts/lint.py`) plus a check that `_rates.py` is up to date.
- `./scripts/dev.sh fmt` — auto-fix whitespace/newline issues only. Long lines and tabs must be fixed by hand.
- `./scripts/dev.sh gen` — regenerate `ledgerlite/_rates.py`.

Prefer `dev.sh test` over bare `python3 -m unittest`: without `LEDGERLITE_HOME` set, `tests/test_report.py` fails at import and the CLI test fails. Running `dev.sh test` also writes `.dev-test-stamp` (gitignored); ignore it.

Run the CLI: `python3 -m ledgerlite.cli report [--by category|month] [FILE]`. Without FILE it reads `$LEDGERLITE_HOME/ledger.csv` and raises `RuntimeError` if the variable is unset.

## Exchange rates

- Edit `data/rates.csv` (columns `currency,eur_per_unit`), never `ledgerlite/_rates.py`. The latter is generated and carries a source hash.
- After changing the CSV, run `./scripts/dev.sh gen`, and commit both files together. `dev.sh lint` fails if they are out of sync.
- README mentions editing `_rates.py` directly; that is outdated.

## Layout

- `ledgerlite/parser.py` — CSV text to `model.Transaction` (frozen dataclass). Raises `ParseError` with a line number (header is line 1, data starts at line 2).
- `ledgerlite/currency.py` — conversion via `EUR_PER_UNIT`; raises `UnknownCurrency`.
- `ledgerlite/report.py` — grouping, amount formatting, table rendering.
- `ledgerlite/cli.py` — argparse entry point; `main(argv, out)` is injectable for tests.
- `tests/` — `unittest` (not pytest). Test data is `tests/fixtures/ledger.csv`; the report tests assert exact totals derived from it, so changing the fixture means updating those expectations.

## Conventions

- Python 3, stdlib only. Don't add third-party dependencies.
- Lint limits: 99-character lines, no tabs, no trailing whitespace, final newline. Applies to `ledgerlite/`, `tests/` and `scripts/`.
- Add tests alongside new behavior in the matching `tests/test_*.py`, using `unittest.TestCase`.
- Before finishing a change, run `./scripts/dev.sh test` and `./scripts/dev.sh lint`, and report any failures as they are.
